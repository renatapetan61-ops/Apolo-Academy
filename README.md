# Apolo Academy

Aplicativo Android nativo de aprendizagem de desenho, desenvolvido em Kotlin e Jetpack Compose.

## Objetivo
Ensinar desenho do nível iniciante ao avançado, com trilhas progressivas, exercícios práticos, acompanhamento de progresso e espaço para um tutor de inteligência artificial.

## Estado atual
Este repositório estava vazio. Esta primeira etapa cria a base nativa Android; ainda não representa um aplicativo publicado nem inclui um serviço de IA conectado.

## Requisitos
- Android Studio recente
- JDK 17
- Android SDK (compileSdk 35)

## Executar
Abra o projeto no Android Studio e aguarde a sincronização do Gradle. Se necessário, gere o Gradle Wrapper pelo Android Studio.
